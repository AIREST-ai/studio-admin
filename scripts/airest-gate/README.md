# فحص أيرست — المهمة ٢٩٠

فحص مستقل ببلاي رايت. لا يكتب في كود الموقع. يخرج برمز ١ عند الفشل، و٢ عند نقص الدليل فقط، وصفر إذا نجحت الحالات الست عشرة. غياب الحساب أو خدمة المقارنة لا يُحسب نجاحاً.

## التشغيل

يحتاج بايثون، ونود، وتبعيات الموقع في نسخة البناء المستقلة.

```sh
python3 -m pip install -r requirements.txt
python3 -m playwright install chromium
python3 check.py --url http://127.0.0.1:8796 --source sources/1618 --build-copy builds/1618 --out results/new-current
python3 check.py --url http://100.78.122.119:8798 --source sources/premerge-correct --build-copy builds/premerge-correct --out results/new-8798
```

مسار النتائج يجب أن يكون جديداً. المصدر للقراءة فقط، ونسخة البناء مستقلة. التشغيل الافتراضي يستعمل أمر بناء المشروع كما هو. خيار ويب باك اختياري؛ استُعمل في النتيجتين السابقتين وفشل. تصحيح أداة الفحص لا يستلزم إعادة ذلك البناء.

قبل البناء، يقارن الفحص محتوى المصدر والأصول العامة والصور والخطوط والأنماط والسكربتات والإعدادات، وملفات الحزم والقفل وإعدادات نكست وتايب سكربت والملفات البرمجية في الجذر. يسجل بصمة كل مدخل والفروق في ملف مستقل، ويرفض البناء عند نقص مدخل أو زيادته أو تغيره. تشمل مجلدات مدخلات هذا المشروع:

```text
src public media assets fonts styles scripts config lib
build-inputs.json
```

الأسرار وملفات البيئة والتبعيات المثبتة والمخرجات خارج البصمة. وجود ملف القفل مطلوب؛ البصمة لا تثبت تطابق التبعيات المثبتة معه. مدخلات المصدر المرتبطة رمزياً تحتاج نسخة فعلية، بينما لا يدخل ربط مجلد التبعيات في المقارنة. يعاد فحص بصمة المدخلات في نهاية التشغيل لكشف تغيرها أثناء الفحص.

الدخول الحقيقي يستخدم حساب اختبار مأذوناً من متغيرين يضبطهما صاحب الحساب خارج الملفات والسجلات. لا يصنع الفحص جلسة ولا يحاكي استجابة الدخول.

```text
AIREST_TEST_EMAIL
AIREST_TEST_PASSWORD
```

## الشروط المعلنة

١. بناء نسخة المصدر المطابقة.
٢. وصول الزائر إلى الدخول وظهور حقليه.
٣. قبول الخادم الدخول والانتقال للوحة.
٤. فتح الرئيسية بعد الدخول.
٥. اتجاه الدخول والرئيسية وسمارت بعرض ١٤٤٠.
٦. اتجاه الصفحات نفسها بعرض ٣٩٠.
٧. غياب طبقة الترجمة المعروفة من المصدر.
٨. غياب علاماتها وطلباتها وحزمها في المتصفح.
٩. غياب النصوص القديمة المحددة من مصدر الواجهة.
١٠. غيابها من الصفحات الداخلية، مع قبول إزالة المسار القديم أو تحويله إلى صفحة سليمة.
١١. ظهور سمارت وأداتها.
١٢. استجابة زر الاستفسار في سمارت دون خطأ متصفح جديد.

أربع حالات إضافية محفوظة منفصلة عند الفاحص. تفاصيلها ونتائجها التفصيلية لا تدخل الحزمة العامة. تستخدم هذه الوسيطة عند تسليمها للمشرف وقت الدمج فقط:

```text
--hidden /path/to/private/cases.py
```

غياب الملف المخفي يمنع نتيجة النجاح الكاملة. والملف الذي يسجل صفراً أو بعض النتائج لا يكفي: لا يخرج الفحص بصفر إلا باثنتي عشرة نتيجة عامة وأربع مخفية، بمعرّفاتها المطلوبة دون تكرار، وجميعها ناجحة. المعرّف الزائد أو الموجود في المجموعة الخطأ أو الحالة غير المعروفة يمنع النجاح أيضاً. تظهر سلامة سجل النتائج في التقرير دون محتوى الحالات المخفية.

فحص محدود لهذين الشرطين، ببيانات مصطنعة ولا يفتح الموقع أو ملف الحالات المخفية:

```sh
python3 -m unittest -v test_gate.py
```

## معنى الدليل وحدوده

الفحص يثبت تفاعل واجهة سمارت، ولا يدعي أنه اختبر استجابة خدمة ذكاء خارجية. اختبار النصوص والترجمة يغطي المصدر والمسارات والعلامات المسماة في السكربت؛ لا يثبت غياب كل صيغة ترجمة ممكنة.

التقريران السابقان بصما ملفات مجلد المصدر وحده. النسخة المعدلة توسع المقارنة إلى المدخلات المذكورة أعلاه، ولا تغيّر نتيجة التقريرين السابقين بأثر رجعي. لا تكفي بصمة المدخلات لربط عنوان منشور بنسخة جيت. ملف إثبات المصدر يسجل أرشيف ١٦١٨ وبصمته. مسار المقارنة الصحيح مأخوذ من [تعليق القائد](/CMP/issues/CMP-245#comment-e0b0c9a8-4286-4963-a5eb-68655da72928)، ولا يحتوي مستودع جيت محلياً يثبت معرّف نسخته. لا تُستخدم نتيجة المسار التمهيدي المختلف دليلاً على نسخة المقارنة.

تقرير الخدمة المنشورة والبناء منفصلان: فشل الاتصال ب٨٧٩٨ ليس عيباً مثبتاً في واجهتها، ونجاح بناء مصدر لا يثبت أنه النسخة المنشورة.
