# بوابة أيرست

تشغّل البوابة على طلبات دمج الرئيسي، ومجموعة طابور الدمج، والدفع إلى الرئيسي. لا توجد شروط مسارات أو حالات تتخطى الفحص. تفحص التزام الدمج الذي توفره المنصة، وتثبت نسخه في دليل النتائج.

أداة القبول من [المهمة ٢٩٠](/CMP/issues/CMP-290#document-handoff)، نسختها الثابتة:

```text
ee582e98e5b42fdc5456cc877fd1e79550c86567
```

الملفات الأصلية للفاحص واختباره ومتطلباته منسوخة دون تعديل. بصماتها داخل الحارس. بلاي رايت وتبعياته، ونود وبايثون، ومعرّفات إجراءات المنصة مثبتة بنسخ ثابتة. حزم الموقع تثبت بأمرها المقفل، دون مخبأ أو مخرجات من العامل.

يحفظ المشغّل المصدر من أرشيف التزام المرشح، وينشئ نسختين مستقلتين: واحدة للمعاينة، وأخرى يبنيها الفاحص الأصلي. لكل نسخة تثبيت جديد. هذا يحفظ أداة القبول كما هي، ويمنع إعادة البناء أثناء خدمة المعاينة. تقارن مدخلاتهما بالمصدر قبل التثبيت وبعده، وبالمعاينة بعد البناء وفي نهاية الفحص. ملف تعريف نكست الذي يولده البناء يسجل كمخرج؛ لا يسمح بتغيير مدخل أصلي.

```sh
npm ci
npm run build
npm run start -- --hostname 127.0.0.1 --port PORT
```

التشغيل المحلي، من نسخة جيت مستقلة، ومسار عمل جديد:

```sh
python3 -m pip install -r scripts/airest-gate/requirements-ci.txt
python3 -m playwright install chromium
python3 scripts/airest-gate/guard.py --candidate /path/to/candidate --base /path/to/base --out /path/to/integrity
python3 scripts/airest-gate/run.py --candidate /path/to/candidate --work /path/to/new-run --hidden /private/cases.py
```

جلسة الاختبار والحالات المخفية تأتي من المسار الخاص المأذون وحده. لا ينشئ المشغّل حساباً أو استجابة دخول. أسماء أسرار المنصة المطلوبة:

```text
AIREST_TEST_EMAIL
AIREST_TEST_PASSWORD
AIREST_GATE_HIDDEN_CASES_B64
```

الثالث ترميز قاعدة ٦٤ لملف الفاحص المخفي الأصلي. تحفظه الجهة المخولة ضمن أسرار المستودع خارج الملفات والتعليقات. في التشغيل المحلي يمكن تمرير مساره الخاص بالوسيطة أعلاه. لا يرث البناء أو المعاينة جلسة الاختبار، وتبقى نتائج الحالات المخفية والصور خارج مخرجات سير العمل العامة. غياب أي مدخل أو المعاينة أو التقرير يفشل البوابة.

شرط النجاح هو اكتمال ١٢ نتيجة عامة و٤ مخفية بمعرّفات فريدة، وكلها ناجحة، مع ثبات المدخلات وبقاء المعاينة. يشمل القبول اتجاه ١٤٤٠ و٣٩٠، والترجمة والصفحات المسماة، والدخول والرئيسية وسمارت. حدود الفحص مفصلة في دليل الأداة المنسوخ؛ نجاح آلية البوابة لا يثبت قبول الموقع الحالي.

بعد التركيب، تستخدم الأداة من نسخة الرئيسي السابقة، ويرفض الحارس أي تغيير للبوابة أو للاختبارات القائمة في المرشح، بما فيه الحذف وإعادة التسمية. عند أول تركيب فقط يقبل فرقاً داخل نطاق تركيب البوابة ويتحقق من بصمات الأداة المقبولة. تغيير الأداة لاحقاً يحتاج مسار صيانة مستقل خارج طلبات إصلاح العمال؛ لا تحتوي هذه البوابة استثناء تجاوز.

سير العمل وحده لا يمنع صاحب صلاحية المستودع من الدمج: يلزم أن يكون فحصه مطلوباً في حماية الرئيسي عبر صاحب الصلاحية. هذه المهمة لا تغيّر الحماية أو الصلاحيات. كذلك لا يستطيع ملف سير العمل إثبات سلامته إذا حذف المرشح الملف نفسه قبل وجود فحص مطلوب؛ الحارس يكشف ذلك عندما يشغّل. هذا حد المنصة، ولا يُعرض تركيب الملف كإثبات منع الدمج.

تظهر الأدلة في مخرجات تشغيل المنصة: معرّفا الأساس والمرشح، وبصمات المدخلات، وأوامر البناء ورموزها، وربط عملية المعاينة بالنسخة، وتقرير القبول. في طلبات النسخ الخارجية التي لا تتلقى الأسرار تفشل شروط الدخول والحالات المخفية. لا تستخدم البوابة حدث طلب دمج ذي صلاحيات مرتفعة.
